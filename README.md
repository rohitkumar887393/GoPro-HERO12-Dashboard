\# GoPro HERO12 Dashboard



A Raspberry Pi based dashboard for controlling a GoPro HERO12.



\## Features



\- Camera Power ON/OFF(USB Triggered)

\- Live Preview using JSMpeg

\- Full Screen Preview

\- Record Start / Stop

\- Media Browser

\- Media Download

\- Video Settings Control

\- Ethernet Control via Open GoPro API



\## Raspberry Pi Requirements



\- Python 3

\- Flask

\- Requests

\- RPi.GPIO

\- FFmpeg

\- Node.js

cd \~/Projects/GoPro/dashboard
